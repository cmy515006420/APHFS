# Figure renderer portability policy v3.1

This release distinguishes three separate reproducibility claims:

1. `SCIENTIFIC_RESULT_REPRODUCIBILITY`: immutable results and released aggregate source data
   reproduce the registered endpoint summaries, intervals, costs, and figure content.
2. `VECTOR/PDF_FIGURE_REPRODUCIBILITY`: canonical PDF and SVG figure outputs generated by the
   project scripts must reproduce byte-for-byte.
3. `RASTER_PREVIEW_RENDERER_VARIATION`: PNG files are external Poppler rasterizations and are not
   canonical scientific outputs.

PNG files are convenience previews and may differ at the pixel level across Poppler versions. PDF and SVG are the canonical deterministic figure artifacts.

Public tests therefore require PNG integrity, valid dimensions, nonempty content, and parity when
both canonical PDFs are rasterized by the same local `pdftoppm`. They do not compare release-build
PNG bytes with PNG bytes produced by an arbitrary Poppler version.

The release test records `pdftoppm -v`, operating system release, and architecture at runtime.
The v3.1 release-build environment was `pdftoppm version 26.05.0`, `Darwin 23.5.0`, `arm64`.

This portability correction changes neither figure data nor any scientific result.
